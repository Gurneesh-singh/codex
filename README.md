# Codex

A starting repository for projects developed with Codex on the web.

## Working with Codex

1. Select `Gurneesh-singh/codex` in Codex and choose its cloud environment.
2. Describe the feature, fix, or project you want to work on.
3. Review the changes and validation results, then create a pull request when ready.
4. Review and merge the pull request on GitHub.

This repository currently has no application code, dependencies, or test suite.
Add setup and testing instructions here as the project develops.
